# 웹 데모 이미지 출처

`scripts/build_site.py`가 만든 축소 이미지(768×480)다. 저장소의 코드와 라이선스가 다르다.

- `sweep/`, `orbit/`: SPIN 시뮬레이터의 Tango 3D 모형(vpulab/SPIN, GPL-3.0)을 SPEED+ 자세 라벨로 Blender에서 렌더링한 이미지.
- `lightbox/`, `sunlamp/`: SPEED+ 데이터셋(Park et al., Stanford SLAB)의 실물 조명(HIL) 이미지. CC BY-NC-SA 4.0, 비상업적 사용만 허용.
  - 출처: https://purl.stanford.edu/wv398fc4383
